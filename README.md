# Luna Arcana Tarot 使用说明

这是一个可直接运行的专业塔罗占卜网站原型，包含完整 78 张塔罗牌、主题选择、牌阵选择、Yes / No、抽牌解读、历史记录、收藏和备注功能。

手机端已经做了专门适配：第一屏只显示个人档案与本次问题；点击“进入塔罗抽取”后才显示主题、牌阵、洗牌和抽牌；抽完牌后才显示解读结果。结果页使用牌位切换，避免整页长篇滚动。

PWA App：网站已经支持添加到手机主屏幕。重新部署后，用手机浏览器打开公网地址，选择“添加到主屏幕”即可像 App 一样打开。支持基础离线缓存，已访问过的核心页面和资源可以离线打开。

抽牌页为了适合手机，只展示 18 张可选牌背，但实际抽取仍来自完整 78 张塔罗牌库。若希望解读更贴近个人情况，可以展开“精准模式”，补充当前背景、时间范围和最想确认的一点。

关于准确度：当前版本是本地规则解读，不连接真实 AI 或真人塔罗师。它现在会先识别用户问题类型，再结合主题、牌阵位置、正逆位、背景信息和牌面倾向给出“直接结论”。如果后续要进一步提升，可以接入 AI 解读接口，让模型根据用户背景生成更个性化的完整报告。

专业塔罗 skill：`tarot-skill.js` 是独立的本地解读引擎，负责识别问题类型和提问方式。它会区分用户是在问结果、原因、对方想法、行动建议还是时机，再结合牌名、正逆位、牌阵位置和背景信息生成直接回答、牌位解说和行动建议。结果页还提供“完整塔罗师式解读”，结构为直接判断、整组牌能量模式、逐张牌位解读和最后建议。页面流程在 `app.js`，专业解读规则在 `tarot-skill.js`，后续可以替换为 AI API 或更完整的命理/塔罗知识库。

新版解读会额外做牌阵关系判断：比较当前与未来、阻碍与建议、我与对方、选项 A 与选项 B，以及逆位比例。整体结论不再只由单张牌决定，而是由整组牌之间的关系推导。

深层解答：完整解读会根据用户当前提问生成“更深层的问题”分析，包括表面问题、真正核心、潜在恐惧、当前卡点和下一步验证策略，让解读更贴近用户实际处境。

个人档案：可以填写称呼、生日、出生时间、出生城市和现居城市。为了隐私安全，不建议填写具体门牌地址。当前版本会基础推算太阳星座、生肖和年柱五行倾向，并把这些信息作为解读语境。真正精确的星盘需要天文星历，完整八字需要节气与农历换算，后续可以接入专业命盘库或 API。

星盘 skill：`astrology-skill.js` 会根据生日、出生时间生成基础星盘视图，包括太阳、月亮、上升的近似位置、元素倾向和占星解读。当前为本地近似推算，不等同于专业天文星历排盘。

印度占星 skill：`indian-astrology-skill.js` 提供独立印占页面，会生成近似北印度式命盘、上升 Lagna、月亮 Chandra、月宿 Nakshatra、Rahu/Ketu 业力轴和逐项解说。历史记录现在可以从导航随时查看。

## 电脑打开

在项目目录运行：

```bash
node server.js
```

然后打开：

```text
http://localhost:4173
```

## 手机打开

手机和电脑需要连接同一个 Wi-Fi。

当前这台电脑的局域网访问地址是：

```text
http://192.168.1.4:4173
```

如果手机打不开，请确认：

- 电脑上的预览服务正在运行。
- 手机和电脑连接的是同一个 Wi-Fi。
- Windows 防火墙没有拦截 Node.js 的网络访问。
- 如果电脑 IP 变化，重新查看电脑的 WLAN IPv4 地址，再把地址中的 `192.168.1.4` 换成新的 IP。
